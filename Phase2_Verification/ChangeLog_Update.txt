5. build_int8_engine.py (NEW FILE)
================================================================================
WHAT IT DOES:
  - Builds a TensorRT INT8 engine from ONNX using calibration images.
  - Uses TensorRT Python API with IInt8EntropyCalibrator2.
  - Loads images from --calib_dir, resizes to 224x224, normalizes (ImageNet stats).
  - Feeds batches through calibrator to compute quantization scales.
  - Saves engine (.trt) + calibration cache (.cache) for reuse.

USAGE:
  python build_int8_engine.py \
    --onnx wildfire_detector/best_model.onnx \
    --calib_dir Seperated_Dataset/D_Fire/Fire/images \
    --output wildfire_detector/best_model_int8.trt

MUST RUN ON THE ORIN (TensorRT engines are hardware-specific).

6. phase2_verification/benchmark_inference.py

  - Added "int8" to --backend choices (was: pytorch, tensorrt; now: pytorch, tensorrt, int8)

WHY:

  editing config.yaml between runs. Clean progress output for large datasets.

9. CRITICAL BUG FIX: predict_crops_majority_vote return type
================================================================================
WHAT WAS WRONG:
  predict_crops_majority_vote() returns final_class as INTEGER (0 or 1).
  benchmark_inference.py compared: result["final_prediction"] == "Fire"
  This ALWAYS evaluated to False → ALL 6216 predictions classified as NoFire.

FIX:
  Changed comparison to: result["final_prediction"] in ("Fire", 1)
  Now works regardless of whether the return is string or int.

IMPACT:
  Without this fix, all benchmark accuracy results were meaningless (100% FN).

10. 7-Stage Timing Instrumentation (all function_class files)
================================================================================
WHAT CHANGED:
  Previously: 4 stages (metadata_and_region, crop_and_resize, batch_and_normalize,
              inference_and_vote)
  Now: 7 stages matching thesis Table 13:
    1. input_and_metadata      — bbox parsing, coordinate extraction
    2. region_validation       — inside/outside/partial check + clip
    3. crop_extraction         — multi-scale crop_bbox_scaled calls

    6. model_inference         — forward pass (with CUDA sync)
    7. majority_vote           — softmax, argmax, vote aggregation

FILES CHANGED:
  - wildfire_detector/function_class_demo.py (_phase2_inner)
  - wildfire_detector/function_class_demo_TensorRT.py (_phase2_inner)
  - wildfire_detector/function_class.py (_phase2_inner)
  - wildfire_detector/function_class_TensorRT.py (_phase2_inner)

  All four now store timings dict with the 7 keys above + "total".
  self.last_phase2_timings = timings (accessible after each phase2 call).

11. predict_crops_majority_vote() → 3-tuple return
================================================================================
WHAT CHANGED:
  Old return: (final_class, avg_conf)  — 2 values
  New return: (final_class, avg_conf, times)  — 3 values

  times dict contains: {'prepare_batch': ..., 'inference': ..., 'postprocess': ...}
  Callers unpack: final_label, avg_conf, infer_timings = predict_crops_majority_vote(...)
  timings['model_inference'] = infer_timings['inference']
  timings['majority_vote'] = infer_timings['postprocess']

FILES CHANGED:
  - wildfire_detector/utils_phase2_flow.py (both predict functions)
  - All four function_class files (3-tuple unpack)

15. visualize_predictions.py (NEW FILE)
================================================================================
WHAT IT DOES:
  Generates crop visualization plots for error analysis (thesis section 5.8).
  Reads predictions.csv from a benchmark run, filters errors (FP/FN),
  loads original images + YOLO labels, runs the crop+classify pipeline,
  and saves annotated plots with per-crop predictions.

MODES:

  --fp_only   : False positives only

  --images    : Specific images by filename (comma-separated)

USAGE:
  python visualize_predictions.py --dataset ..\Seperated_Dataset\D_Fire \
    --predictions benchmark_results\resnet18_tensorrt\predictions.csv --errors

OUTPUT:
  visualizations/false_positives/FP_<name>.png
  visualizations/false_negatives/FN_<name>.png
  visualizations/selected/OK_<name>.png
